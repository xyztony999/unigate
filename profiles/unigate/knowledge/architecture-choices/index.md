# UniGate 当前架构边界

最新决策 ADR-039：首版在线、离线后置。旧 ADR 冲突以此为准，历史不删除。

## 已确认范围

- 单一主办方自托管、多场活动，内置报名及外部名单独立检票；独立指无需内置报名，仍需联网访问服务器。
- 手机/平板浏览器工作人员检票及自助 kiosk；统一公网服务裁决，不设 Android 主/备协调节点、本地 Web/API、局域网证书/DNS、离线核销队列或云地交接。普通热点可用于联网，不构成业务服务器。
- 断网暂停该端，恢复先核对同一操作 ID；单端掉线不等于全场停用。服务器原子检查剩余名额和持久化结果，未知回包不可当作失败重开一笔。
- 组码、分批、名额容量、审核、差额增员、自助开关/截止、五角色、通知、来源、统计及留存沿用已确认规则。现场公众报名变更冻结仍保持，负责人现场操作受授权与容量约束。
- 首版 500 人以内及 2–5 台同时检票为设计目标；未做设备或性能验证。

## 已确认架构、功能与需求

用户已选择采用在线 AA v0.2（ADR-040）：核心业务域含资格与名额、现场准备与控制、核销异常；支撑业务域含活动规则、名单接收、凭证交付、统计交付、留存清理；基础数据域无独立维护模块；平台支撑域含身份授权、连接任务、审计及幂等。AA v0.3 补齐与既定流程一致的检票员/本组原操作查询角色，不授予全局权限；逻辑模块不自动等于微服务。

## 技术与集成

Java/Spring Boot 后端及 Vue Web 已确认，项目内 springboot-vue-web 提供契约规约。D3提出JDK21、Spring Boot4.1.1、Vue3、PostgreSQL18为详细设计候选，尚未锁定依赖或执行SQL；不自动引入微服务、MQ或专用页面引擎。

CSV/XLSX、飞书问卷和腾讯文档进入统一映射/校验/来源流程。个人测试、组织接入预留保持，开发者与实际文档权限待验证。连接凭据和任务执行在平台基础能力管理，业务是否生效由名额/资格服务判断。

中国大陆活动及服务器，海外受限明细查看/境内导出交付，字段和动作分权；启用前明确主体用途和实际规则。明细默认活动后 30 天可配置，实际清理及备份恢复单列设计，浏览器不整份缓存名单。
