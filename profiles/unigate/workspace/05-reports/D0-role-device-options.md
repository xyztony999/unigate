# UniGate 角色与设备选择

日期：2026-10-20；状态：用户已选 A1/B2，分别见 ADR-034/035。编号仅针对本批，不覆盖前批 A1/B1/C1；下文保留原选项。

## A：角色划分

1. 五类角色（推荐）：系统管理员、活动负责人、检票员、校方只读人员、参与者。管理员管部署/账号/连接凭据；负责人管获授权活动的配置、名单、审核、现场异常及导出；检票员查找/核销；校方按活动及字段授权查看；参与者仅本组。一个账号可兼任管理员与负责人，系统管理员不因此默认获全量活动明细。
2. 四类角色：合并系统管理员和活动负责人，其他角色与权限边界同上。管理操作更少，但部署管理和活动明细管理不再分开。

两种方案均遵守已确认的仅负责人处理现场加人补录、查看与导出分权。参与者包含内置及外部名单中的持票组；自助 kiosk 是受限终端模式，不是能够浏览全部名单的新角色。完整矩阵在 AA/FL 中集中确认。

## B：首版现场检票客户端

1. 全部使用 Android App（推荐）：主设备、备用设备及其他检票端均为 Android 手机/平板。管理后台及报名领票仍为 Web，技术偏好 Vue 不变。
2. Android 主备设备，加浏览器检票端：其他检票设备还需能用浏览器操作。须在 D1 明确局域网访问、可信 HTTPS、相机及设备授权方案并实测；不将普通局域网 HTTP 自动等同于可扫码。

选 B1 不自动确定 Android 开发语言或 UI 框架；选 B2 不自动扩展 iPad 主设备，也不保证所有浏览器与机型均兼容。
