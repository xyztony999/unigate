# UniGate 在线首版核心流程

日期：2026-10-20；版本：v0.4；状态：已确认业务基线（ADR-037/039）的在线细化，正式编码与 API/PageSpec 仍待设计。

## 依据与对象

最新首版在线、离线后置（ADR-039）。活动包含配置、容量、报名组和检票窗口；报名组包含来源、资格、总名额及凭证，逐次核销记录包含本次人数、终端、操作人和操作 ID。通知尝试、审核决定、导入批次和审计分别留痕，不作为报名者身份。

总名额为 1 加随行人数，未收或未填随行人数为 0。手机/邮箱可为空，不作为普遍唯一键。主报名者不必每批同行，持有效组码按剩余名额入场，不识别随行者自然人身份。

## 报名与资格

待审核可转有效、拒绝或取消；立即模式及已获资格来源通过字段和容量校验后直接有效。待审核不占额，批准时原子占整组，不足不通过。待审核及拒绝无有效入场码。

自助改人数和取消默认关闭、按活动开启，截止为报名截止与现场开始中较早者；已核销后不自助变更。有效组减少人数释放差额，即时模式增员原子补足差额，审核模式仅审核新增部分并保留原批准数。被拒绝后重提留痕，不能绕过容量/审核。取消使票证失效，不删除入场事实。

票证有效性、资格和入场进度分别维护。进度为未入场/部分入场/全部入场，不因第一次核销把整组标为全部到场。

## 来源及领票

文件/API 接收后做映射、预览、错误与来源核对，负责人明确来源有效资格或待审核；有效来源仍校验容量等约束。稳定源 ID 处理同源重传，跨源重复联系方式只提示人工核对。已批准/核销记录不由后续源数据直接覆盖；现场新答卷不能直接增加名额。

报名后可保存私密状态页；邮箱可用时通知领票，失败不撤销资格。查询、变更和入场凭证能力分离。找票通过已提供联系方式验证或负责人核对补发并撤销旧码，不凭尾号直接补发；无联系方式的外部名单由工作人员辅助核对并转负责人补发。

## 现场准备、开启与控制

准备活动、有效名单、获授权检票端及公网服务可达性；现场开启时冻结公众新增报名、审批占额、人数修改及取消释放，处理在途事务。在线首版不自动重开这些入口。负责人通过获授权在线动作办理现场增额、补录及异常，遵守容量且增额与到场分别记录。

现场业务窗口为准备、开放、暂停和结束等候选状态，正式枚举在 API 设计锁定。活动窗口和单台终端的网络状态分开：一端掉线不自动暂停全活动；终端不可访问服务器则停止该端核销。

工作人员及 kiosk 扫码后确认本次人数，服务端原子检查有效资格、活动窗口、权限和剩余名额，持久化核销事实再返回成功。kiosk 无名单搜索，只接收当前组最小字段，普通检票员无增额、补录、纠错或导出权限。

超时、刷新或重试时使用同一操作 ID。未知结果显示待确认，恢复网络后查询原操作；同一载荷重试返回原结果，不新增一次核销，不能本地排队即绿灯。前端禁用重复点击只是交互，幂等与并发约束在服务端保证。

## 故障与纠错

首版无 Android 主备或本地服务接管，原恢复 B 已不适用。网络/服务器不可达时暂停，恢复访问后继续同一在线服务；不承诺一定能通过换热点解决服务器故障。

重复、无效、剩余不足及误检分别提示；误检由负责人填写理由并生成关联更正，不抹去原记录，不作为离场或再次入场入口。具体更正数量边界和冲突错误在 PRD/API 细化。

没有默认启用纸质名单人工放行或自动宽松入场功能；如以后需要，另行定义权限、人数及对账，不能冒充已完成系统核销。

## 收尾、统计与生命周期

结束后停止现场变更，核对服务器中的核销、更正及名额调整；同一操作重传不增加统计。公众报名等变更不会因网络恢复或结束检票自动重开。

报表区分报名申请组数、待审核、有效组数及名额、累计核销、未使用名额、现场增额/补录，标明查询时点；更正保留原数及关联依据，不展示无离场数据支持的当前在场人数。

明细按活动、字段、动作及期限授权，查看/导出分权。默认活动结束后 30 天可配置，实际清理受管服务器、暂存、生成导出及端上最小必要数据，备份恢复防复活；浏览器不预存全量名单。已下载文件和已发送邮件由交付约定处理，真实海外主体/用途在启用前落实，当前无实际发送。
