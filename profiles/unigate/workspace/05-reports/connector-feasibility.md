# 首批名单连接器：飞书问卷与腾讯文档

日期：2026-10-20；状态：设计前研究，尚未账号授权或接口实测，非 D3 完整 API 规格。

## 已确认需求

首版支持通用 Excel/CSV 导入，并为飞书问卷和腾讯文档设计 API 名单接入（ADR-012/013）。其他平台不是本次已确认的首批连接器。

## 飞书问卷

官方产品说明指出问卷数据存储于多维表格；开放平台提供多维表格及记录接口。因此建议按“问卷对应数据表 → UniGate 来源映射”设计，实际表格标识、字段和权限需用目标账号验证。问卷公开填写链接本身不等于读取答卷授权。

来源：[飞书问卷官方说明](https://www.feishu.cn/content/wechat_post_1751)、[多维表格开放能力](https://open.feishu.cn/search?from=doc&page=1&pageSize=10&q=%E5%A4%9A%E7%BB%B4%E8%A1%A8%E6%A0%BC)、[记录查询文档](https://open.feishu.cn/document/docs/bitable-v1/app-table-record/search)。

权限需同时核对应用/API 权限和目标资源访问范围；用户身份与应用身份不能混为一谈。官方应用权限说明分别描述两类身份，实际使用何者取决于用户账号、组织及授权条件。记录查询页本次文本工具未提取到正文，不据此填入未经核实的精确限频和 token 时长。

来源：[官方身份权限说明](https://www.larksuite.com/hc/zh-CN/articles/000472088408-%E8%87%AA%E5%BB%BA%E5%BA%94%E7%94%A8%E7%9A%84%E6%9D%83%E9%99%90%E4%BB%8B%E7%BB%8D%E5%92%8C%E5%AE%A1%E6%A0%B8%E8%A7%84%E5%88%99%E6%8E%A8%E8%8D%90)。

## 腾讯文档

官网提供收集表和在线表格 Open API。网页文本工具对部分页面未提取正文，本次通过直接读取官方公开 HTML 的 main 正文核实以下内容；未运行页面脚本、未调用用户数据接口。

收集表可调用 `POST /openapi/drive/v2/forms/{formID}/result` 生成结果表，官方列出 `scope.form` 权限。这不是直接返回全部答卷 JSON 的只读接口，会生成结果资源；需实测返回的关联表标识、重复调用行为及收集表版本。

来源：[收集表接口索引](https://docs.qq.com/open/document/app/openapi/v2/form/)、[生成收集结果](https://docs.qq.com/open/document/app/openapi/v2/form/result.html)。

普通在线表格可使用 `GET /openapi/spreadsheet/v3/files/{fileId}/{sheetId}/{range}` 读取范围，文档列出表格读取权限以及范围上限。建议分块读表；不能把行号当作永不变化的答卷 ID。字段排序、行插删和重复同步识别策略在 D3 前验证。

来源：[范围读取接口](https://docs.qq.com/open/document/app/openapi/v3/sheet/get/get_range.html)。

官方授权使用 OAuth 授权码流程。令牌交换及 API 请求由后台发起，需管理应用标识、用户身份及访问令牌。应用创建和部分权限可能涉及审核，权限变化后需重新授权；用户账户类型与实际可申请能力尚未验证。当前不采用“仅企业才能接入”或“个人一定能全部接入”的结论。

来源：[授权流程](https://docs.qq.com/open/document/app/oauth2/)、[应用权限](https://docs.qq.com/open/document/app/scope.html)、[接入教程](https://docs.qq.com/open/document/app/get_started.html)。

## 连接器设计建议

- 云端后台负责接入外部平台和保存凭据；不把平台应用密钥分发到每台检票设备。现场检票依赖准备好的 UniGate 名单与局域网主设备，公网中断不等待第三方平台响应。
- 各平台数据统一进入来源记录、字段映射、预览校验与冲突处理；来源标识在验证后采用稳定记录 ID，无法取得稳定 ID 时另定显式策略。
- 同步重试幂等；外部数据修改不能覆盖本地检票事实。取消、删除、名额变化和活动现场冻结边界待确认。
- 显示最近成功同步时间、待处理错误、授权失效及重连入口；定时或手动同步、是否订阅事件暂未决定。
- 问卷字段和同行人数语义需明确“含本人总人数”与“不含本人随行数”，不能直接复制数字而不转换。
- 文件导入作为已确认的并行接入方式；API 权限暂不可用时需明确显示连接器未就绪，不虚报自动同步成功。

## 当前问题与限制

Q-05c 已解决：两平台均先用个人账号测试，保留企业/学校组织账号接入（ADR-014）。账号类型已确认，但实际开发者资格、应用审核、管理员权限及数据读取能力仍未验证；具体资源类型、字段、同步方向、频率及样例留待后续明确。研究不代表连接器已实现或已接通，不替代 Gate 1。
