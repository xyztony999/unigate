# UniGate D0 集中选择

日期：2026-10-20；状态：本批已确认 A1、B1、C1，分别见 ADR-031、032、033。以下保留原选项和影响作为依据。

依据用户最新“后续问题都给选择题、加快”的要求，集中提问三项关键边界。支持用 A1/B2/C1 等方式回答。建议选项不代表用户已同意。

## A / Q-03d：独立检票准备范围

1. 后台准备活动与名单，Android 在现场断公网后独立检票（推荐）。
2. Android 单机即可建活动、导入文件、检票及统计，全程可以不部署后台。

A2 会增加移动端本地管理、导入、身份及活动配置流程；云端第三方 API 拉取和报名网页不因该选择自动变成本地能力。主备接管及有效权限约束仍需满足。

## B / Q-03e：现场开始后的云端名额写入

1. 启动现场检票后冻结云端新增、审批占额、改人数及取消释放，交给现场负责人处理（推荐）。
2. 主设备在线时允许云端协调这些操作；公网断开时暂停相关云端写入。

两种模式均可保留云端只读查询和带同步时间的报表。外部平台可继续产生答卷，但冻结/暂停期间不得未经现场确认自动写入有效名额。邮件重试不视作名额写入。选择不等于已实现双写一致性。

## C / Q-05d：外部名单的审核资格

1. 负责人按来源配置为“有效名单”或“待审核”，导入预览/连接配置时明确确认（推荐）。
2. 所有外部记录一律先待审核，通过后才发码并占额。

有效名单也必须通过字段、容量和来源幂等检查；第三方任意字段不能自动授予审核资格。“有效名单”来源仅在获准的写入阶段和容量内生效，现场期间遵循 B 的选择。疑似跨来源重复先保留来源、提示人工核对，不用相同联系方式静默合并。
