## 第一部分：文档概述

### 1.1 背景与目标

把在线首版模块与权限展开为可审阅入口及操作，覆盖手机/平板工作人员检票、自助 kiosk、报名、来源与统计。离线及 Android 主备后置。

### 1.2 文档定位

本文按用户类型描述菜单/入口和功能点，追溯 application-arch.md v0.5。菜单包含页面、同页动作与公开/受限终端流程，不要求每项都成为独立导航页。数据库、API 字段和视觉布局在后续设计定义。

### 1.3 范围

五角色：系统管理员、活动负责人、检票员、校方只读人员、参与者。一个账号可兼任，实际动作仍按活动/字段/期限校验。kiosk 是受限模式，不是第六种业务角色。

## 第二部分：功能清单

### 本清单概览

管理员配置身份与连接，负责人组织活动并处理受权异常，检票员查找及核销，校方只读获准数据，参与者限本组。后台任务隐式执行仅表示技术过程，功能入口不授予额外业务权限。ADR-047 重划分后凭证交付并入核心业务域「资格、名额与凭证」，检票员与参与者的原凭证类条目随之归入核心业务域。

```text
        │   └── FL-C-007 提交结果确认 — 核对获准原核销操作；网络恢复后沿用原 ID，不将超时当作未入场。
        └── 操作事实持久化
            └── FL-C-006 本端操作记录 — 查看获准的本人/终端核销记录及异常，不提供全活动个人名单或全局审计。
```

## 附录

### 覆盖与权限边界

- 6 个业务模块/17 个业务子模块及 3 个平台模块/6 个技术子模块全部有角色入口覆盖；菜单按用户类型和操作展开，不要求与 L4 一对一。
- 多个条目可归入同一页面；编号是功能追溯标识，不是最终路由。实际 PageSpec 只从 D3 API 合同推导，本清单不是提前生成的页面合同。
- 管理员不因管理连接或任务获得报名内容，负责人和校方字段/导出分权；普通检票员无现场增额、补录、更正及补发权限。
- 参与者平台身份/终端/结果条目均限本组和获准操作，不是注册管理账号、为自己授权设备或浏览其他组。
- 断网暂停，恢复原操作 ID；平台幂等不提供离线放行，不将本地缓存当服务器提交成功。

### 后续需细化

本菜单与产品/领域模型原由 ADR-041 确认；ADR-047（2026-11-11）按新模块结构重挂 43 项功能的归属（条目 ID、菜单名与功能点描述不变），AA v0.5/API v0.4 同步。真实连接器权限、海外启用配置及设备验证保持独立验证项。
