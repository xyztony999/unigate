# Vue 页面与交互规约

## 基础

Vue 主版本建议使用 3；确切版本、构建工具、TypeScript 与 UI 库在架构阶段锁定，当前未创建前端工程。后端/Web 约定不自动决定 Android 原生技术。

D4 从 D3 API 和已确认业务规则生成 PageSpec。每页注明路由、用户、进入条件、布局、字段/类型/可见性/必填、初始/加载/空/错误状态、动作/API、权限、返回及异常路径、触控和可访问性要求。桌面管理页面、移动报名页面和固定终端分别设计适用布局。

## 页面类型与映射

- 列表：筛选、分页、稳定排序、操作及权限；查询字段和响应字段引用 API 字段名。
- 表单：录入与条件必填、前后端一致校验、重复提交、版本冲突和保存后去向。
- 详情：状态、关联信息、敏感字段可见范围及可用动作。
- 审核：待办、详情、决定及理由、名额/状态冲突与失败后状态。
- 导入及连接配置：授权状态、字段映射、预览、逐行错误、冲突处理和结果；不将配置保存显示为已经同步成功。
- 现场终端：就绪、识别、人数确认、请求不确定、成功、重复、无权/无效、离线/断联、接管中等依 API 区分；终端身份切换、管理解锁和清屏有独立流程。
- 报名及领票：仅显示当前凭证获准访问的信息；状态页与有效入场码展示条件分开。

交互图标、颜色和声音不能作为唯一状态信号；提供清晰文字和触控操作。主操作在提交期间防止重复点击，但真正的幂等由后端契约保证。客户端超时不等于服务端未完成，不展示未经确认的成功或失败。

## 原生边界与隐私

Web 摄像头、HTTPS 与局域网访问按目标浏览器实际能力验证。应用外壳、原生桥接与纯浏览器的能力分别注明，不承诺页面部署就具备原生热点或服务器能力。

自助端和工作人员端基于后端允许的字段显示，不先下载全部个人信息再用 CSS 隐藏。公共资源离线缓存与私密资料分开规定；重启、过期、注销和终端回收需清理对应内容。公开扫码字符串不能无条件变成管理会话。
