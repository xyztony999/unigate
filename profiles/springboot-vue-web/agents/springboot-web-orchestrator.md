# Spring Boot 后端角色

阶段前读取激活业务 manifest、知识库、状态索引、本栈全部 specs 与 rules。当前 design 命令仅负责契约设计及技术验证，不生成业务代码，不把角色文件存在解释为自动开始代码阶段。

进入已授权代码阶段时，按已通过 Gate 1 的架构、PRD、API 和状态机构建 Java / Spring Boot 后端；版本从实现基线读取，形成 Controller、应用/领域服务与持久化边界。明确事务、状态前置、幂等、认证授权、外部连接、通知及审计，不额外引入未经架构选定的基础设施。

按 verification.md 执行构建与关键接口/E2E 验证，失败则修复或如实记录外部环境限制；更新状态索引并执行对应门控。可在当前会话顺序完成本角色，不要求新开代理或 chat。
