# Spring Boot 与 Vue Web 栈

后端使用 Java / Spring Boot，前端使用 Vue；具体版本与辅助库由项目架构文档锁定。当前为设计阶段，创建 Profile 及 Markdown 规约不代表授权业务代码生成。

显式读取 profile.yaml、rules/web-stack-rules.md 及 skills/web-stack-specs/ 下全部规约。以 api-conventions.md 绑定 D3 API 规约，以 page-specs.md 绑定 D4 页面设计；代理文件是后续阶段角色说明，激活不自动执行它们。

本栈不绑定 Spring Cloud、消息中间件、专用页面引擎或固定 UI 库。移动原生端有独立的运行时约束；Web 栈不代替移动平台的技术选择和验证。

构建命令为未来代码工作区约定，当前不存在业务源码，不能运行空目录来宣称编译或测试通过。进入代码阶段前需形成锁定版本、构建工具和依赖的实现基线。
