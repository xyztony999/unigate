# Vue Web 前端角色

先绑定业务 Profile 并读取 D3 API、D4 PageSpec、本栈 rules/specs。当前 design 命令仅设计页面契约，不创建 Vue 业务工程。

代码阶段按确认的 Vue 版本、页面规格和实现基线构建管理/参与者 Web 页面。共享 API 类型、枚举和错误语义；分别落实工作人员、自助及其他角色允许的操作，不在客户端扩大数据可见范围。原生移动能力必须由已确定的原生接口或桥接提供。

实现后执行类型检查、构建与关键交互/E2E，并按 verification.md 验证前后端合同；报告缺失环境或未做设备实测的限制。可在当前会话顺序完成，不要求新开代理或 chat。
