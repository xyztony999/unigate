# Web 栈规则

- SW-01：设计命令只交付文档及配置；代码阶段按已授权阶段和实际工作区执行。
- SW-02：版本、持久化方案和部署形态从项目架构读取；规范没有声明的中间件不作为隐含必需项。
- SW-03：API、DTO、PageSpec、枚举、权限和操作前置状态对齐；关键并发及幂等在服务端保证。
- SW-04：凭据和个人信息有独立访问范围，设备与用户权限按服务端校验；日志、错误与导出不泄露秘密。
- SW-05：外部同步、通知与关键业务状态分离，失败和恢复有明确语义；记录真正持久化后才返回对应成功结果。
- SW-06：代码阶段完成适用编译、类型检查和契约/关键 E2E；设备实测与模拟结果分开报告。
- SW-07：Gate 1 和 Gate 2 结果按证据记录，Profile 检查通过不能替代设计或代码门控。
